# 分类页背景替换设计

## 目标

将分类页当前的春日书房背景替换为更华丽的暖金色二次元图书馆插画，同时保持现有内页结构、阅读层、暗色模式和响应式行为不变。

## 素材

- 作品：8K Ultra HD Anime Girl Masterpiece: Enchanted Library Glow
- 作者：Tadokiari
- 来源：https://wall.alphacoders.com/big.php?i=1317278
- 原图尺寸：8736 x 4896
- 本地文件：`source/images/brand/category-library-glow.webp`

原图下载后缩放至最长边不超过 1920 像素，转换为 WebP，并将文件控制在 450 KB 以内。正式页面引用本地文件，不依赖第三方图片外链。

## 页面行为

- 仅 `/categories/` 及其子路径使用新背景。
- 桌面端背景定位为 `54% center`，保留人物面部和右侧暖光。
- 手机端背景定位为 `57% center`，窄屏裁切时优先保留人物面部。
- 沿用现有浅色遮罩、暗色模式滤镜和半透明阅读层，不增加新动效。
- 其他首页、标签、归档、关于和文章页图片保持不变，避免重复使用。

## 来源记录

在 `source/images/brand/sources.json` 中新增 `inner-categories` 条目，记录本地文件、作品页面与作者，保留后续追溯能力。

## 验证

- 场景映射测试必须断言分类页使用新文件，且分类子路径行为一致。
- 完整执行 `npm test`，确认 Hexo 构建和现有站点契约不回归。
- 检查 `1440 x 1000` 与 `390 x 844` 分类页截图，确认人物面部可见、文字无重叠、图片成功加载。
- 检查浅色和暗色模式，确保阅读层对比度足够。
