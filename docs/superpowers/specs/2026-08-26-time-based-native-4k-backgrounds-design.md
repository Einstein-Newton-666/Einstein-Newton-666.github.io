# 分时原生 4K 背景设计

## 背景

当前首页使用三张约 1920 像素宽的图片，并提供对应的 3840 像素 WebP。现有 4K 文件由低分辨率原图放大，虽然像素尺寸达到 4K，但没有原生 4K 细节。用户认可当前图片的视觉方向，希望用原生高分辨率图片替换，并让首页根据访客本地时间自动切换场景。

归档页现用星空海湾背景。用户已在本地对比页选定暖光图书馆图片作为替代。导航栏应保持 Redefine 2.9.0 官方行为，不增加透明度或背景覆盖。

## 目标

- 用四张原始宽度至少为 3840 像素的横向图片替换首页三个现有场景。
- 保持现有图片的审美方向：开阔天空、云层、原野或山谷，光线明显，具有动画电影感。
- 图片可以包含人物，也可以由人物承担视觉重点，但桌面标题安全区不得被复杂主体占据，移动端裁切必须保留主要人物或核心景物。
- 首页按照访客本地时间选择初始场景，并保留手动切换能力。
- 将归档页背景替换为已选定的暖光图书馆原生高分辨率图片。
- 保持普通屏幕和移动端的轻量加载策略。

## 非目标

- 不改变首页文章列表、侧栏、标题排版或滚动提示结构。
- 不修改 Redefine 的导航栏模板、样式或滚动状态逻辑。
- 不修改分类、标签、关于和文章页背景。
- 不引入远程运行时图片、自动轮播、持续动画或新的第三方依赖。
- 不使用低分辨率放大图冒充原生 4K。

## 图片选择与资源规则

首页四个时段分别使用晨光、白日、黄昏和夜晚场景。视觉筛选以当前三张首页图为参照，优先选择大面积天空、山谷、草地、云层、星空、银河或极光等开阔构图。人物允许出现，但不得导致标题遮挡或移动端只剩残缺局部。

每张图片必须满足以下条件：

- 来源文件宽度不低于 3840 像素，且不是由较小版本放大得到。
- 横向构图，优先接近 16:9；超宽图片必须同时通过桌面和手机裁切检查。
- 不包含明显水印、站点标记、低质量 JPEG 块或破损细节。
- 来源页、原始尺寸、作者信息（可取得时）及处理方式写入 `source/images/brand/sources.json`。
- 正式页面只加载 `source/images/brand/` 中的本地 WebP，不依赖源站。

每个场景生成三档资源：约 320 像素宽的切换器缩略图、约 1920 像素宽的标准版、约 3840 像素宽的 4K 版。标准版目标不超过 450 KB，4K 版目标不超过 1.2 MB；如果继续压缩会产生明显色带或损坏人物细节，允许记录具体例外。

归档页采用本地对比页中的“暖光图书馆”候选，原图尺寸为 5156×3402。它同样生成标准版与 4K 版，并替换归档场景映射和来源记录。

## 分时与交互设计

首页按浏览器本地时间选择初始场景：

| 时段 | 时间范围 |
| --- | --- |
| 晨光 | 05:00–10:59 |
| 白日 | 11:00–16:59 |
| 黄昏 | 17:00–19:59 |
| 夜晚 | 20:00–04:59 |

页面初始化时只选择一次，不设置定时器持续切换，避免阅读过程中背景突然变化。用户点击缩略图后立即切换场景；手动选择只在当前页面生命周期内生效，刷新或重新进入首页后再次按本地时间判断。

场景数组增加稳定的 `period` 和时间范围数据。时间到场景的选择逻辑写成可独立测试的纯函数，首页初始化通过该函数决定初始索引。现有 `srcset`、`sizes` 和缩略图按需加载策略继续保留。

## 导航栏与降级

自定义 CSS 不新增任何 `.navbar-container` 或 `.navbar-content` 背景、透明度、模糊度规则。导航栏在首页横幅、滚动后和内页上的表现全部由 Redefine 2.9.0 官方样式控制。

JavaScript 不可用时，主题配置中的首页浅色背景仍能显示。分时函数遇到无效日期时回退到白日场景。4K 资源加载失败时，浏览器可通过 `srcset` 或基础 `src` 使用标准版。归档背景加载失败时，现有页面底色和内容卡片仍保证文字可读。

## 验证

- 为四个边界时刻及无效日期增加单元测试，确认时段映射正确。
- 检查首页四个场景都声明缩略图、标准版和 4K 版，归档映射指向新资源。
- 验证所有来源记录完整，原始宽度不低于 3840 像素，正式文件可解码。
- 执行 `npm run clean`、`npm test` 和 `npm run build`。
- 在 1440×1000、3840×2160 和 390×844 视口检查首页四个场景与归档页。
- 检查标题不遮挡主体、手机裁切保留人物面部或核心景物、文字无重叠、图片请求档位正确。
- 检查浅色、暗色与低动态偏好；确认导航栏表现与 Redefine 官方站一致且没有自定义透明度覆盖。
- 确认搜索、RSS、MathJax、字数统计及 GitHub Pages 构建不回归。
