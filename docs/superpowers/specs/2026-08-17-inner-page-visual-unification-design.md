# 内页视觉统一设计

## 背景

当前站点使用 Hexo 7.3 与 Redefine 2.9.0。首页通过 `home_banner` 和自定义脚本呈现全幅场景，但分类、标签、归档、关于及文章页仍采用 Redefine 的默认纯色背景，因此从首页进入内页时视觉变化明显。

Redefine 2.9.0 已是 npm 当前最新版本，升级依赖不能消除这一差异。该差异来自主题对首页与内页采用不同布局，而不是版本落后或构建异常。

## 目标

- 保留内页紧凑、适合阅读的布局，不复制首页全屏横幅。
- 使用现有插画、主题色、遮罩、圆角与阴影建立统一的视觉语言。
- 各页面尽量使用不同图片，减少重复。
- 同时支持浅色模式、暗色模式、桌面端与移动端。
- 不修改 `node_modules`，确保主题升级后自定义效果仍可维护。

## 非目标

- 不修改 RSS/Atom 输出格式或删除 RSS 导航入口。
- 不增加新的网络图片、字体服务、后端或第三方运行时依赖。
- 不改变首页场景切换、文章路由、搜索、MathJax 或 GitHub Pages 工作流。
- 不把内页改成与首页相同的全屏大图结构。

## 页面与图片映射

| 页面类型 | 背景图片 | 说明 |
| --- | --- | --- |
| 分类 | `book-spring.webp` | 纸页与春景适合内容整理语义 |
| 标签 | `morning-mountains.webp` | 开阔层次适合标签索引 |
| 归档 | `river-sunrise.webp` | 纵深景观呼应时间线 |
| 关于 | `tech-lab.webp` | 明亮研究室对应个人与技术信息 |
| 文章 | 文章 `cover` | 复用文章自身语境，不额外重复固定背景 |
| 文章无封面 | `firefly-side.webp` | 使用现有备用图片 |

首页继续使用现有三个可切换场景，头像继续使用 `castorice-avatar.webp`。

## 实现设计

### 页面识别

扩展 `source/js/anime-theme.js`，根据当前路径识别分类、标签、归档、关于和文章页面，并在 `document.documentElement` 上设置稳定的 `data-anime-page` 属性。同时设置页面背景所需的 CSS 自定义属性。

文章页优先读取页面已有的 Open Graph 图片作为背景，但只接受同源站内路径；没有有效文章封面时使用备用图片。路径无法识别时不启用内页背景，以保持 Redefine 默认行为。

初始化必须可重复执行，兼容 Redefine 的单页导航。页面切换后旧属性和旧 CSS 变量先清理，再应用新页面状态，避免从分类页进入标签页后仍显示分类背景。

### 视觉层

扩展 `source/css/anime-theme.css`：

- 在非首页的 `.page-container` 后方放置固定背景层，不向主题模板插入额外结构。
- 浅色模式使用柔和白色遮罩，暗色模式使用深色遮罩并降低图片亮度。
- 导航区域使用与首页一致的青色、樱粉和黄铜点缀，但保持文字对比度。
- `.page-template-container`、`.archive-container` 和文章内容区域使用半透明实色背景；模糊仅作为增强，必须同时提供不依赖 `backdrop-filter` 的可读底色。
- 页面标题使用现有宋体方向，正文继续使用系统无衬线字体。
- 卡片圆角不超过 8px，避免嵌套卡片和过强阴影。

### 响应式与动效

- 桌面端背景固定覆盖视口，内容宽度沿用 Redefine 现有约束。
- 移动端使用独立的 `background-position`，保证主体区域不被完全裁掉。
- 内页不增加持续动画，只保留主题已有的页面显现和链接反馈。
- `prefers-reduced-motion: reduce` 下不增加任何新过渡。

## 错误与降级

- JavaScript 未执行时，页面保持当前 Redefine 默认布局，不影响内容访问。
- 背景图片加载失败时，CSS 底色和半透明内容层仍保证文字可读。
- 不支持 `backdrop-filter` 的浏览器使用实色透明背景。
- Atom XML 不加载站点主题脚本或背景样式，继续作为订阅数据输出。

## 验证

- 扩展 `test/verify-site.mjs`，确认分类、标签、归档、关于和文章页面仍生成，并加载统一主题脚本与样式。
- 为页面路径映射和文章封面降级建立可执行测试；先验证测试在缺少实现时失败，再实现功能。
- 执行 `npm ci`、`npm run clean`、`npm test`。
- 启动本地服务，检查所有背景图片、CSS 和 JS 返回 `200`。
- 在 `1440x1000` 与 `390x844` 下检查分类、标签、归档、关于和文章页的浅色/暗色模式。
- 检查导航和正文无重叠，文字对比度足够，移动端图片裁切合理，键盘焦点可见。
- 确认首页场景切换、搜索、RSS、MathJax、字数统计和 GitHub Pages 构建不回归。
