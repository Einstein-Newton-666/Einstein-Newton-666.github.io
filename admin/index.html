连接你的博客仓库

  1. ① 在 GitHub 上生成令牌（权限已预填）

    打开后只剩两步：Repository access 选 Only select repositories 并勾选本博客仓库， 再点最下方 Generate token。权限已预选 Contents: Read and write，名称与有效期说明也填好了。

  2. ② 把生成的令牌粘贴到这里
  3. 源码仓库（一般不用改）

    文章源码在这个私有仓库里；公开的 Einstein-Newton-666.github.io 只存放构建产物，往它提交源码等于把私密文章公开，编辑台会拦截。

令牌只保存在本机浏览器，请求直接发往 api.github.com，不经过本站或任何第三方服务。 手机同样可用：粘贴一次后浏览器会记住，不用每次登录。

为什么不能直接用 GitHub 登录？

“用 GitHub 登录”需要一个后台保管 client_secret 来换取访问令牌。 本站是 GitHub Pages 上的纯静态站点，没有后台；把密钥放进公开页面等于公开泄漏，所以只能由你自备令牌。 令牌权限随时可在 GitHub 上撤销，风险可控。

⚠️ 如果上面的按钮打不开，多半是 github.com 被网络阻断； 可改用手机流量、或换一个能正常访问 GitHub 的网络生成令牌。编辑台本身只要网络能访问 api.github.com 就能用。

先选一篇文章开始编辑

  • 电脑端：左侧列表点选文章
  • 手机端：点顶部「📄 文章列表」展开列表，选完会自动收起
  • 可改标题、日期、分类、标签与正文；配图拖进编辑区即上传
  • 保存会直接提交到 main 分支，GitHub Actions 自动发布
